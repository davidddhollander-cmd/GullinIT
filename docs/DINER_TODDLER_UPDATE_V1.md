# Diner frame cleanup and toddler redraw — 19 October 2026

The diner artwork crosses the nominal four-by-three grid in both original sheets. The former bounding-box mapping included neighbouring hands, hats and shoes, and clipped some of the intended actor's extremities. This was source extraction contamination, rather than texture filtering.

`tools/prepare_pier_diner.gd` now separates the 12 complete connected actor silhouettes from each full source sheet, sorts them into their original pose order, and packs each into a 400 × 400 cell with transparent gutters and a shared foot baseline. The original source images remain intact. Production uses `pier-diner-retro-clean.png` and `pier-diner-motion-clean.png`; existing animation names, speeds, food anchors and gameplay hit timing are retained. `tools/map_pier_diner_sheet.py` rebuilds the atlases and updates both sprite manifests so regeneration cannot restore the bad grid crops.

The toddler was regenerated with the built-in image-generation tool, using the diner and approved mum as style references and the earlier toddler as an identity reference. The full prompt and generated source are saved in `assets/reference/toddler-diner-v1/`. Yellow sunhat, coral band/shirt, brown hair, teal dungarees and yellow shoes are preserved.

`tools/prepare_toddler.gd` extracts and prepares 16 poses in `assets/sprites/toddler-diner-style.png`: 64 × 64 cells, binary alpha, 0.5 display scale, sole baseline 60. Standing figures are 44 source pixels / 22 world pixels tall, compared with approximately 18 visible world pixels previously. The shorter crying-run silhouette reflects its crouched stride. Source pixels use the same half-scale treatment as the new adult cast. The old painted toddler remains archived and is no longer the runtime source.

`tools/map_toddler_diner.py` registers idle, eat, walk, cry and cry_run clips and their food anchors. `ToddlerArt` aligns the separate stealable food on frame changes and mirrors it with the child. Toddler rendering uses nearest filtering and its genuine transparent alpha. A separate canvas offset plants the feet correctly without counting transparent padding as character height. Tears follow the slightly taller face. Existing family movement, help requests, handover, theft and scoring remain authoritative; a moving upset child now uses the new crying-run artwork.

Review image: `assets/archive/previews/toddler-diner-comparison-v1.png`, containing actual production sprites at their runtime sizes and enlarged pose details. The full toddler contact sheet is `assets/archive/previews/toddler-diner-style-sheet-v1.png`. The latter has a transparent background; the comparison board is preferable for evaluating edges.

Validation includes all 24 diner and 16 toddler cells: transparent gutters and a single connected actor, atlas bounds, foot alignment, taller child height, hard alpha, food movement/mirroring, theft and family return at 30/60/120 Hz. Final rendered integration run: **11,029 checks, zero failures**, with an empty gameplay error log. Results are in `test-output/toddler-diner-validation.log`; retained screenshots are in `assets/previews/diner-toddler-update-v1/`. The cookie peck fixture now places the gull relative to the visible snack, preserving its range precondition after the palm moved. Gameplay peck reach is unchanged.

Reproduction order: run the diner mapper with Python; run Godot with `--headless --path . --script tools/prepare_toddler.gd`; run the toddler mapper with Python; run `tools/validate.ps1 -Capture`. The original generated art and full prompt remain available independently of these deterministic atlas tools.
