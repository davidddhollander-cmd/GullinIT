# Pier diner theft-reaction source

These are the complete, uncropped source images produced by the built-in image
generator for the pier diner's theft-surprise and failed-chase fist-shake pilot.
The runtime atlas is derived only by isolating, uniformly scaling and aligning
the complete figures on a shared 400 px cell and foot baseline.

- `diner-reactions-source-pass-1.png`: initial complete 6x2 reaction sheet.
- `diner-reactions-source-pass-2.png`: first arm-role correction.
- `diner-reactions-source-pass-3.png`: second arm-role correction, retained even
  though it is not used by the runtime atlas.
- `diner-fist-shake-source.png`: final readable six-frame fist-shake strip.
- `PROMPTS.md`: every prompt used for these generated sources.

The original diner pose and motion atlases remain untouched. The production
reaction atlas lives at `assets/sprites/pier-diner-reactions-v1.png`.
