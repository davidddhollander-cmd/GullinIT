# Original shopper reaction pilot sources

`shopper-reactions-source.png` is the untouched complete-character sheet generated
with the built-in image generator on 21 October 2026. `PROMPT.txt` preserves the
full prompt and reference list. Runtime extraction is performed by
`tools/prepare_shopper_reaction_pilot.gd`; it appends the twelve mapped cells to
the versioned `assets/sprites/shopper-diner-style-v2.png` atlas without modifying
the prior production atlas.
