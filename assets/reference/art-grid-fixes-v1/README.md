# Art-grid fixes v1 source set

This folder preserves untouched copies of every production image used to build task 049 candidates. `tools/prepare_art_grid_fixes.gd` performs source-preserving crop, composite, hard-alpha and nearest-neighbour resize operations. The old man is never drawn or redesigned by code.

The candidate files remain registered only in `data/art_lab.json`; the live game assets and `data/sprites.json` are unchanged.
